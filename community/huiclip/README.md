# 回形夹 · HuiClip

HuiClip 是基于 [Paperclip](https://github.com/paperclipai/paperclip) 的独立中文社区版，许可沿用 MIT。

这个 npm 包包含固定的社区源码快照和 `huiclip` 命令。前置依赖为 Node.js 24.11+、pnpm 9.15.4 和 tar。安装包后执行 `huiclip setup` 下载锁定依赖并构建界面，再执行 `huiclip run`。默认地址为 `http://127.0.0.1:1549`，数据保存在 `~/.huiclip`。执行 `huiclip info` 可以查看实例配置、数据库端口、CLI 路径和建议的服务名。

完整使用指南在 [HuiClip 仓库](https://github.com/yangyanlei-jiang/huiclip/tree/community/zh-cn-v1)。
